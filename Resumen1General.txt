TECNOLOGÍAS UTILIZADAS
--------------------------------------------------------------------------------
- Vue.js 3 (Composition API)
- Quasar Framework v2
- Vue Router
- JavaScript (ES6+)
- CSS Variables para theming

OBJETIVO DEL PROYECTO
--------------------------------------------------------------------------------
Juego de Ta-Te-Ti (tres en raya) funcional con interfaz moderna y responsiva.
Sistema de turnos, detección de ganador, empates y reinicio de partida.

ARQUITECTURA Y DECISIONES
--------------------------------------------------------------------------------

1. PATRÓN COMPOSABLE
   - useTaTeTi.js contiene TODA la lógica del juego
   - Los componentes son "tontos", solo reciben props y emiten eventos
   - Facilita testing y reutilización de lógica

2. COMPONENTES SEPARADOS
   - Cada parte del juego es un componente independiente
   - Facilita mantenimiento y escalabilidad
   - Permite reutilizar componentes en otros contextos

3. FLUJO DE DATOS
   - JugarTaTeTi.vue → consume useTaTeTi()
   - JugarTaTeTi.vue → pasa datos a componentes hijos via props
   - Componentes hijos → emiten eventos hacia arriba
   - Estado unidireccional y predecible

FUNCIONALIDADES IMPLEMENTADAS
--------------------------------------------------------------------------------

1. TABLERO DE JUEGO
   - Grid 3x3 responsive
   - Celdas clickeables solo si están vacías
   - Animación al aparecer fichas
   - Hover effect en celdas disponibles

2. SISTEMA DE TURNOS
   - Alterna entre 'X' y 'O'
   - Indicador visual del turno actual
   - Animación de pulso en turno activo

3. DETECCIÓN DE GANADOR
   - 8 combinaciones ganadoras verificadas
   - 3 filas, 3 columnas, 2 diagonales
   - Mensaje de victoria con animación

4. DETECCIÓN DE EMPATE
   - Valida cuando todas las celdas están llenas
   - Solo si no hay ganador
   - Mensaje de empate

5. CONTROLES
   - Botón Reiniciar: resetea el juego completo
   - Botón Volver: navega a página de inicio
   - Responsive en mobile

6. RESPONSIVE DESIGN
   - Tablero se adapta a pantallas pequeñas
   - Botones en columna en mobile
   - Textos escalables

LÓGICA DEL COMPOSABLE useTaTeTi
--------------------------------------------------------------------------------

ESTADO REACTIVO:
- tablero: Array de 9 posiciones (null, 'X' o 'O')
- turnoActual: String ('X' o 'O')
- juegoTerminado: Boolean
- ganador: String (null, 'X' o 'O')

MÉTODOS PRINCIPALES:
- realizarJugada(indice): Coloca ficha, valida, cambia turno
- verificarGanador(): Revisa las 8 combinaciones posibles
- reiniciarJuego(): Resetea todo el estado a inicial

COMPUTED:
- esEmpate: true cuando tablero lleno y sin ganador

VALIDACIONES:
- No permite jugada si celda ocupada
- No permite jugada si juego terminado
- Solo cambia turno si jugada válida

CONVENCIONES DE CÓDIGO
--------------------------------------------------------------------------------
- Variables, funciones y clases: ESPAÑOL
- Nombres descriptivos (manejarClick, realizarJugada, etc.)
- camelCase para variables y funciones
- PascalCase para componentes
- Props tipadas con validación
- Emisión explícita de eventos con defineEmits

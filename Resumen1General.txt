PROYECTO: TA-TE-TI (TRES EN RAYA)
================================================================================

DESCRIPCIÓN GENERAL
--------------------------------------------------------------------------------
Aplicación móvil de juego Ta-Te-Ti (tres en raya) desarrollada con Vue.js 3
y Quasar Framework. Incluye sistema de configuración de usuario, detección
de ganador/empate, y diseño responsive con tema oscuro personalizado.

TECNOLOGÍAS PRINCIPALES
--------------------------------------------------------------------------------
- Vue.js 3 (Composition API)
- Quasar Framework v2
- Capacitor (para Android)
- Vue Router
- Capacitor Preferences (almacenamiento nativo)
- JavaScript (ES6+)
- CSS Variables (theming)
- Tabler Icons (iconografía)

ARQUITECTURA Y PATRONES
--------------------------------------------------------------------------------

PATRÓN COMPOSABLE:
- Toda la lógica del juego está en useTaTeTi.js
- Toda la lógica de configuración está en useConfiguracion.js
- Los componentes son presentacionales (reciben props, emiten eventos)
- Facilita testing y reutilización

PATRÓN SINGLETON:
- useConfiguracion usa refs globales para compartir estado
- Permite actualización reactiva entre múltiples componentes
- El nombre del usuario se sincroniza automáticamente en toda la app

PATRÓN MODULAR:
- ConfiguracionPage.vue es un contenedor escalable
- Cada configuración en su propio componente (ConfiguracionUsuario.vue)
- Fácil agregar nuevas configuraciones (idioma, sonido, tema)

FLUJO DE DATOS:
- Estado unidireccional y predecible
- Props hacia abajo, eventos hacia arriba
- Composables manejan la lógica de negocio

FUNCIONALIDADES IMPLEMENTADAS
--------------------------------------------------------------------------------

JUEGO TA-TE-TI:
- Tablero 3x3 interactivo
- Sistema de turnos (X y O)
- Detección de 8 combinaciones ganadoras
- Detección de empate
- Línea ganadora animada con efecto neón
- Reinicio de partida
- Animaciones en fichas y celdas

CONFIGURACIÓN:
- Cambio de nombre de usuario
- Almacenamiento persistente (Capacitor Preferences)
- Validación de datos
- Notificaciones de éxito/error
- Actualización reactiva en toda la app
- Modal con cierre inteligente (click afuera, Enter, botones)
- Estructura modular preparada para futuras configuraciones

INTERFAZ:
- Header con nombre de usuario
- Drawer lateral con navegación
- Diseño responsive (mobile-first)
- Tema oscuro personalizado
- Iconografía Tabler Icons

SISTEMA DE MODALES REUTILIZABLES
--------------------------------------------------------------------------------

COMPONENTE: ModalConfirmacion.vue
UBICACIÓN: src/components/Modales/

CARACTERÍSTICAS:
- Modal genérico con dos botones (Aceptar/Cancelar)
- Completamente personalizable vía props
- Slot para contenido personalizado
- Cierre inteligente (click afuera, Enter, botones)
- Estilizado con paleta de colores del proyecto
- Eventos: aceptar, cancelar, update:modelValue

PROPS PRINCIPALES:
- modelValue: Control de visibilidad (v-model)
- titulo: Título del modal
- mensaje: Mensaje descriptivo
- icono: Ícono Tabler (sin prefijo 'ti-')
- textoBotonAceptar/textoBotonCancelar: Textos personalizables

TABLER ICONS
--------------------------------------------------------------------------------

CONFIGURACIÓN:
- Instalado vía: @tabler/icons-webfont
- Importado en App.vue
- No requiere configuración en quasar.config.js

USO EN COMPONENTES:
<i class="ti ti-nombre-icono"></i>

- ti-user-edit: Editar usuario

- ti-check: Éxito

REFERENCIA: https://tabler.io/icons

ALMACENAMIENTO NATIVO
--------------------------------------------------------------------------------

TECNOLOGÍA: Capacitor Preferences
INSTALACIÓN: @capacitor/preferences

CARACTERÍSTICAS:
- Almacenamiento clave-valor nativo
- Persiste entre sesiones
- Compatible con Android/iOS
- Asíncrono (Promises)

CLAVES USADAS:
- nombre_usuario: Nombre del jugador
